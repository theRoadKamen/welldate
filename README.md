# 电商数据工作台

当前版本是阶段二的本地导入测试版：支持上传生意参谋商品日报 XLS 和无界计划报表 CSV，并按已确认口径计算核对结果。

## 启动

```bash
python3 app.py
```

打开 <http://127.0.0.1:8765>，选择报表文件后点击“导入并核对”。

## 当前支持

- 生意参谋商品日报：GMV、GSV、退款率、商品转化率汇总、客单价。
- 无界计划报表：花费、总成交金额、汇总投产比、点击量。
- XLS 通过本机 LibreOffice 转换后读取，原文件不会被改写。

## 当前限制

- 本版本不落盘、不建立正式批次数据库。
- 当前只做一次导入核对，不做店铺/系列管理和趋势看板。
- 重复上传、缺失日期、系列商品匹配将在下一步加入。
