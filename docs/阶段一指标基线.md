## 4. 已冻结计算规则

### 4.1 通用规则

- 金额保留两位小数。
- 字段名包含“率”或“费比”时按百分比展示。
- 投产比按数值展示，不加百分号。
- 原始值、标准化值、计算结果分层保存。
- 分母为 0 时显示空值或“暂无数据”，不得显示为 0。
- 原始空值不得自动转成真实 0。

### 4.2 商品层面

```text
GMV = 支付金额
GSV = 支付金额 - 成功退款金额
退款率 = 成功退款金额 / 支付金额
转化率 = 商品支付转化率
客单价 = 支付金额 / 支付件数
投产比 = 无界报表投入产出比
推广费比 = 花费 / GMV
```

### 4.3 店铺和系列层面

比例类指标先汇总分子和分母，再重新计算，不平均商品比例。

```text
GMV = SUM(支付金额)
GSV = SUM(支付金额) - SUM(成功退款金额)
退款率 = SUM(成功退款金额) / SUM(支付金额)
转化率 = SUM(支付买家数) / SUM(商品访客数)
客单价 = SUM(支付金额) / SUM(支付件数)
投产比 = SUM(总成交金额) / SUM(花费)
推广费比 = SUM(花费) / GMV
```

### 无界计划样本（2026-10-07）

```text
花费合计 = 100.00
总成交金额合计 = 313.48
店铺/系列投产比 = 313.48 / 100.00 = 3.13
```

计划级 `投入产出比` 保留原始值。店铺或系列层面不得将计划级投产比求和或简单平均。
